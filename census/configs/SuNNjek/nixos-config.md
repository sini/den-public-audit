## 3. Defined, disabled and ambiguous alternatives

Niri has substantive KDL settings; VS Code and Starship are enable-only. Vim-full is explicitly the system default editor, not Neovim. The generic Dux greeter fallback is Hyprland ([`modules/aspects/dux.nix:51`](https://github.com/SuNNjek/nixos-config/blob/f40297e9d045387227869245163e7e2b6c7799f9/modules/aspects/dux.nix#L51)), but both selected niri.dux aspects override it. This does not prove the default user session, so no default WM row is claimed.

Dux has separate Hyprland source settings; those alone do not enable the compositor.
