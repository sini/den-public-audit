## 3. Defined, disabled and ambiguous alternatives

Neovim/LazyVim is the default editor; Helix is an enabled configured alternative, explicitly not default ([`home/features/helix.nix:8`](https://github.com/ivokun/kebun/blob/1038ddc22989c43931a147959c64395efb6b661f/home/features/helix.nix#L8)). Fish is the explicit account shell; configured Zsh remains available. GNOME utilities, KDE applications and swaybg wallpaper are not full desktops/compositors.


## 4. Machine roles and limits

Source labels Sakura laptop and Ume desktop ([`modules/aspects.nix:200`](https://github.com/ivokun/kebun/blob/1038ddc22989c43931a147959c64395efb6b661f/modules/aspects.nix#L200), [`modules/aspects.nix:207`](https://github.com/ivokun/kebun/blob/1038ddc22989c43931a147959c64395efb6b661f/modules/aspects.nix#L207)). Laptop capability feeds display/lid fragments; Ume is described as pre-install, so selection is static intent, not runtime use.

Complete two-host literal inventory; generated script and application packages are not standalone configured editor outputs.
