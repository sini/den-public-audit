## Reading by Reader A

### Shape summary
A pure namespace provider ([`modules/dendritic.nix:1-7`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/dendritic.nix#L1-L7), "namespace provider, no hosts"). Namespace `garden` holds eight aspects: `palette`, `toolkit`, `terminal`, `shell` are real; `daemon`, `ctl`, `tui`, `observability` are stubs (their bodies are comments such as "S1 stub", [`modules/aspects/daemon.nix:6`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/daemon.nix#L6)). A Rust workspace (palette core, theme generators, daemon/ctl/tui placeholders) and a Quickshell QML shell sit beside the Nix, built as flake packages ([`modules/packages.nix:18-58`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/packages.nix#L18-L58)). The one idea: one palette file drives every tool, via generated theme files that tools include from a mutable directory.

### Lessons for the rewrite
1. A mutable-file resource needs a declared contract in the quirk itself: path, seed-once, never-symlink, owner. [`palette.nix:6-16`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/palette.nix#L6-L16) is the clearest specification in the pilot set. A `mutable-file` collector should carry it as data, not a comment.
2. Activation ordering and failure semantics are resource properties. [`terminal.nix:26-31`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/terminal.nix#L26-L31) (after palettes, best-effort) and [`shell.nix:50-97`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/shell.nix#L50-L97) (keyed on a state file, never fails) belong in the protocol.
3. A namespace-provider layout (no flake module, closed over the library's own `self`) isolates the consumer far better than importing the repo's module tree. Prefer it.
4. Publish adapters as their own kind (`garden.terminal` themes tools it doesn't enable); don't count them as app presets.
5. Don't publish stub aspects as selectable names: they inflate the index and `garden.shell` pulls them in. Gate with a completeness flag.

- **Mutable state contract:** first-activation palette and settings copies remain ordinary writable files; existing runtime choices survive later activations ([`modules/aspects/palette.nix:6`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/palette.nix#L6), [`modules/aspects/palette.nix:17`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/palette.nix#L17), [`modules/aspects/shell.nix:30`](https://github.com/adanoelle/garden-shell/blob/e9c3a6b47fafaca0143daeb0da63e82209b2c9e8/modules/aspects/shell.nix#L30)).
