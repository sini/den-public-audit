## Reading by Reader A

### Shape summary
Namespace `crocuda`, created in the library's own flake ([`modules/namespaces.nix:8`](https://github.com/crocuda/crocuda.nixos/blob/226387d876ae3b70b47d510f75e21973d23f7bae/modules/namespaces.nix#L8)). Server modules (DNS, I2P/Tor, mail, web, finance nodes, shell, docker) are leaves under `modules/aspects/`. Each leaf keeps native-format config under `dotfiles/` (every `dotfiles/` reference I scanned resolves to a file in the tree). A `crocuda.batteries.*` group holds system presets and two constructors. The repo also contributes flake-level outputs: a `crocuda_lib` helper set, `deploy.nodes`, `vm-*` packages, a devShell. It runs no host of its own. The README describes an older NixOS-module option API (`crocuda.users`, `crocuda.shell.fish.enable`) that no longer exists in source.
