## 3. Defined, disabled and ambiguous alternatives

VS Code/Zed/Fish have substantive settings. Neovim exists only as an unselected installation/desktop-entry aspect; the explicit editor default is Nano. OmniWM native niri layout settings are not a Niri compositor enable. SDDM KWin compositor is not full Plasma desktop adoption.

- **neovim** (defined, enabled, installed): A live Neovim package/desktop-entry aspect exists, but neither workstation nor Linux desktop/user includes select it. Evidence: [`modules/aspects/neovim.nix:5`](https://github.com/nolvyn/nixos/blob/e0fd0f9f0537a28b68ee802a75051f719a2af203/modules/aspects/neovim.nix#L5).

## 4. Machine roles and limits

Workstation is normalized to explicit desktop configured role for both hosts, without asserting physical chassis. Astraeus Darwin role follows its inventory platform. External mutable checkout symlinks require the repository to remain at the schema flakeDir path ([`modules/schema.nix:10`](https://github.com/nolvyn/nixos/blob/e0fd0f9f0537a28b68ee802a75051f719a2af203/modules/schema.nix#L10)).

Complete literal two-host inventory; the Linux desktop profile is reusable for homes but no standalone home target is declared.
