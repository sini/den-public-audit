The synthesis docs read across all the reviews at once. They are for den maintainers, for authors who want to start
a config, and for contributors to a community aspect library. They use no repository scores. For per-config scores,
see [RANKING.md](/ranking/). For what each config selects, see the [census summary](/census/summary/).

## Contents

- [Public configuration themes](#public-configuration-themes)
- [Library candidate groups and resource inventories](#library-candidate-groups-and-resource-inventories)

## Public configuration themes

[public-themes.md](/synthesis/public-themes/) answers the question: what recurs across the 98 public reviews? Read it if
you maintain den, or if you want a starter template.

| Section | What it answers |
|---|---|
| [Recurring composition patterns](/synthesis/public-themes/#recurring-composition-patterns) | Which layout patterns repeat across configs. |
| [Recurring library units](/synthesis/public-themes/#recurring-library-units-across-the-98-public-reviews) | Which four units at least three repos nominate, and the best source for each. |
| [Recurring den friction](/synthesis/public-themes/#recurring-den-friction-in-98-public-reviews) | Where configs work around den, and what den could do. |
| [Reviewed public target inventory](/synthesis/public-themes/#reviewed-public-target-inventory) | Which hosts, homes and packages the configs declare, by class and system. |
| [Platform and extension coverage](/synthesis/public-themes/#platform-and-extension-coverage-historical) | The historical mechanical signals and lower bounds, and their common overclaims. |
| [Starter-template candidates](/synthesis/public-themes/#starter-template-candidates) | Which configs to adapt as a starter. |

## Library candidate groups and resource inventories

[library-candidates.md](/synthesis/library-candidates/) answers the question: which nominated library units exist, and what
resources does each one own? Read it if you will harvest aspects into a community library.

| Section | What it answers |
|---|---|
| [About this document](/synthesis/library-candidates/#about-this-document) | The sources, the A/B/C grades, the resource vocabulary and what recurrence means. |
| [Preferred sources](/synthesis/library-candidates/#preferred-sources-for-recurring-or-cross-cutting-groups) | The best existing source for each recurring or cross-cutting group. |
| [Resource mechanisms and fleet/app contracts](/synthesis/library-candidates/#detailed-catalog-resource-mechanisms-and-fleetapp-contracts) | The collectors, settings, classes, checkout links, operations and service envelopes. |

| [Coverage and next harvest boundary](/synthesis/library-candidates/#coverage-and-next-harvest-boundary) | What the catalogs cover, and which facts a harvest still needs. |
