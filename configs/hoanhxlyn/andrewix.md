## 1. Shape

flake-parts + import-tree, using the `flake-file` and den `dendritic` flake modules ([`modules/defaults.nix:20-23`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/defaults.nix#L20-L23)). Nearly
all aspects live in an exported `core` namespace ([`modules/namespace.nix:7`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/namespace.nix#L7)), referenced as `<core.x.y>`. Hosts are plain
data built by a local `mkHost` helper ([`modules/hosts.nix:6-163`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/hosts.nix#L6-L163)) with typed facts in `den.schema.host`
([`modules/schema.nix:7-12`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/schema.nix#L7-L12)). Three "variant" aspects (workstation, homelab, wsl) live in `modules/devices/`. Six hosts:
four physical and two WSL.

## 5. den friction

- [`modules/iso.nix:54-57`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/iso.nix#L54-L57): the ISO is a plain `nixosSystem` outside den, so `<den.batteries.unfree>` does not reach
  it and unfree must be re-declared by hand. There is no den path for "a nixosSystem that shares aspects but is not a host".
- [`modules/devices/wsl.nix:19-22`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/devices/wsl.nix#L19-L22): imports `nixos-wsl` and sets `wsl.defaultUser` by hand rather than using den's
  `wsl` battery (den main `modules/aspects/batteries/wsl.nix`). This may be a re-implemented battery.
- [`modules/defaults.nix:21-22`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/defaults.nix#L21-L22): `(inputs.den.flakeModules.dendritic or {})` guards against the module being absent,
  which suggests churn in den's flake-module names.
- [`modules/schema.nix:5-6`](https://github.com/hoanhxlyn/andrewix/blob/bd9927ece041a42e81cd3aa5d22cf6e513b17206/modules/schema.nix#L5-L6): touching `self` inside `den.schema.host` causes infinite recursion, so facts are imported
  relatively.

## 7. Template notes

It is a good example of hosts as typed data plus variant aspects selected from facts. The `core` namespace with dotted
angle brackets is clean, but its 124-file tree is heavy for a first read. IFD on three hosts (approx, niri) makes it a
poor CI or equivalence target without a builder.
