## 1. Shape
flake-parts + import-tree over `modules/`. `modules/den/` holds `hosts/` (11 files: 9 NixOS incl. 2 microvm guests, 1 darwin, 1 nix-on-droid), `users/` registry, `environments/`, `clusters/`, `groups/`, `policies/`, `quirks/`, `classes/`, `batteries/`, `schema/`, and ~450 one-aspect-per-file aspects (path = identity). Users reach hosts via an access policy (`access.nix`, `policies/users.nix`), not per-host lists.

## 2. Common patterns
- `custom schema/classes`: typed per-aspect `settings` mirrored into `host.settings` ([`schema/_settings-type.nix:41-89`](https://github.com/sini/nix-config/blob/7e267a559e4a93f6f83d2f9e96f47b75b227a88c/modules/den/schema/_settings-type.nix#L41-L89)), documented in `docs/host-aspect-settings.md`.
- `quirks`: 49 declarations (`modules/den/quirks/`), collectors in the owning aspect (`A/core/secrets/collector.nix:17-31`).
- `policies`: scoped pipes `pipe.collect` (environment) vs `pipe.collectAll` (fleet) in [`policies/pipes.nix:55-74`](https://github.com/sini/nix-config/blob/7e267a559e4a93f6f83d2f9e96f47b75b227a88c/modules/den/policies/pipes.nix#L55-L74).

## 3. Novel patterns
- Settings mirror: every aspect's `settings` option is auto-surfaced under its identity path on the host (`schema/_settings-type.nix`).
- Aspect split by class key across files (`core/network/tailscale/tailscale.nix`, `tailscale/darwin.nix`).
- Policy co-located with the aspect that needs it (`A/applications/dev/ai/mcp/xmsg.nix:62,70`).
- Guest virtualization as an isolated child host (`A/virtualization/guests.nix`).
- Terranix aspects reading environment data ([`modules/flake-parts/terranix/dns.nix:12-28`](https://github.com/sini/nix-config/blob/7e267a559e4a93f6f83d2f9e96f47b75b227a88c/modules/flake-parts/terranix/dns.nix#L12-L28)).
