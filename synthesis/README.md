# Synthesis

The synthesis docs read across all the reviews at once. They are for den maintainers, for authors who want to start
a config, and for contributors to a community aspect library. They use no repository scores. For per-config scores,
see [RANKING.md](../RANKING.md). For what each config selects, see the [census summary](../census/summary.md).

- [Public configuration themes](#public-configuration-themes)
- [Library candidate groups and resource inventories](#library-candidate-groups-and-resource-inventories)
