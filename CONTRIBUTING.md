# Contributing

This repository is a point-in-time survey, so most contributions are corrections.

## Request a correction

Open an issue that names:

- the config (its page under `configs/`);
- the finding you dispute, quoted or linked;
- why it is wrong, with a link to the source line if you can.

A finding that is wrong at the reviewed revision is fixed, and the score is recomputed if it moves. A finding that
was right at the reviewed revision but has since been fixed upstream is noted, but not rescored, because every
config was read at one revision.

## Remove your config

Open an issue asking for your config to be removed. You don't need to give a reason. The page, its census notes and
its rows are removed. Its scores may stay in aggregate counts.

## Report a security concern

If you find credential material or other sensitive data on any page here, please don't quote it in a public issue.
Open an issue that only says which page is affected, and ask for a private contact.
